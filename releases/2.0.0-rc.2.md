# PlexonHomes 2.0.0-rc.2

Phase 3 consolidation release candidate. This prerelease is required because the accepted Phase 3 source adds SetHome migration/import runtime support beyond `v2.0.0-rc.1`.

## Phase 3 delta

- Adds dedicated `SetHomeMigrationService` for the proven SetHome 6.3 `homes.yml` schema.
- Adds read-only scan/plan/verify/status operations and operator-gated execute.
- Adds source fingerprinting, re-plan protection, conflict/quarantine classifications, and idempotent import identity.
- Preserves existing PlexonHomes records; no silent overwrite or source deletion.
- Bundles `limits.default: 15` to match the verified active SetHome default policy.
- Keeps canonical homes ownership in PlexonHomes; no production migration is executed by this release.

## Compatibility and boundaries

- Java 25 / class major 69.
- Paper API `26.2.build.121-stable`.
- PlexonCore `2.0.4` is a provided runtime dependency and is not shaded.
- SQLite remains bundled as required by PlexonHomes.
- SetHome remains installed until an explicitly approved production cutover.
