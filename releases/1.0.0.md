# PlexonHomes 1.0.0

First stable Core-native homes module for PlexonCraft.

## Included

- Focused `/sethome`, `/home`, `/homes`, `/delhome`, `/renamehome` replacement.
- Core 2.0.3 shared player-watch warmups with movement, damage, quit, death and world-change cancellation.
- Safe teleport validation and bounded nearby fallback.
- Home limits, cooldowns and optional Vault teleport fees/refunds.
- SQLite WAL persistence, backups and read-only Essentials userdata import.
- Paginated GUI, public API/events and diagnostics.

## Runtime

- Paper 26.2
- Java 25
- PlexonCore 2.0.3 or later compatible Core API 2.x runtime

PlexonHomes does not replace unrelated Essentials functions such as spawn, back, warp, heal, feed or economy.
