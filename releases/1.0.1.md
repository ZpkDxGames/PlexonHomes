# PlexonHomes 1.0.1

PlexonCore 2.0.4 lifecycle/provenance maintenance release.

## Fixed

- Replaces the repository-local/system-scoped Core 2.0.3 build dependency with a provided PlexonCore 2.0.4 dependency.
- Pins CI and release verification to the exact PlexonCore 2.0.4 JAR and SHA-256.
- Uses owner-aware Core 2 module state transitions.
- Uses owner-scoped unregister cleanup so PlexonHomes cannot remove another plugin's module registration.
- Removes the hard-coded 1.0.0 lifecycle detail in favor of plugin metadata.
- Makes stable release publication refuse existing release assets.

## Unchanged

Home persistence, Essentials migration, safe destination resolution, player-watch warmups, Vault/TheosisEconomy provider usage, fee charging/refunds, cooldowns, GUI and public API/events are unchanged.

## Certification boundary

Source/CI/release certification does not claim live server deployment, Core READY observation, restart, soak, or Spark validation.
