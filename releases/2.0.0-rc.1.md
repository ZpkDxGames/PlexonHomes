# PlexonHomes 2.0.0-rc.1

Phase 2 release candidate. This is **not** a stable runtime certification.

## Included

- Stable per-home UUID identity; rename/location updates preserve logical identity.
- SQLite schema v2 with v1.0.1 backup/migration, idempotent legacy UUID derivation and future-schema fail-closed behavior.
- Persistence-first cache mutation and post-commit events.
- Reconnect generation ownership for asynchronous profile loads.
- One authoritative teleport attempt through resolve, warmup, charge and terminal `teleportAsync` completion.
- Shared warmup coordinator and PlexonCore shared player-watch cancellation.
- Exact-once fee/refund ownership with Vault response verification.
- Transactional strict config-v2 reload and legacy config backup/upgrade.
- Revision-bound, expiring, one-shot GUI deletion and stale-card protection.
- Cache-only PlaceholderAPI expansion.
- Phase 2 distribution, provenance, checksum and exact-head release gates.

## Rollback

Published rollback: `v1.0.1` / `d20bef0a76cd3006df51d46d67a3e48636650d31`. Restore a pre-v2 data backup before running the 1.x JAR.

## Certification boundary

PlexonCraft runtime migration, live command/GUI/economy behavior, restart/reconnect, Spark/MSPT and >=30-minute soak are not certified by this prerelease and remain mandatory before stable `v2.0.0`.
