# PlexonHomes 2.0.0

Stable GitHub repository closure of the accepted Phase 2 / Phase 3 PlexonHomes runtime line.

## Reliability and data safety

- Stable home UUID identity and SQLite schema v2 preserve logical identity across rename.
- Persistence-first mutations, generation-bound stale-load rejection and bounded executors protect authoritative state.
- One per-player teleport attempt remains authoritative from resolution through terminal `teleportAsync`; duplicate requests are rejected.
- Safe destinations are bounded/revalidated, cooldown begins only after success, and failed charged teleports use at most one checked compensation path.
- Candidate configuration reload is transactional; malformed candidates leave the prior runtime active.
- GUI destructive actions remain actor/owner/home/revision-bound, expiring and one-shot.
- PlaceholderAPI reads cached state only.

## SetHome Phase 3 migration

- Includes the dedicated SetHome 6.3 `homes.yml` provider.
- Scan, plan, verify and status are non-destructive.
- Execute requires a successful plan and unchanged SHA-256 source fingerprint.
- Existing PlexonHomes names are never silently overwritten.
- Invalid worlds, coordinates and records are quarantined/reported.
- Deterministic migration UUIDs make successful imports idempotent, including after later rename.
- Bundled `limits.default: 15` reflects the verified active SetHome default policy.

Migration execution and SetHome decommission remain **operator-gated deployment steps**. Stable release publication does not execute a migration and does not authorize SetHome removal.

## Release verification

The exact final `main` source is rebuilt and tested with Java 25 / Paper 26.2 / PlexonCore 2.0.4. Publication includes `PlexonHomes-2.0.0.jar`, `SHA256SUMS.txt`, `TEST_SUMMARY.txt` and `PROVENANCE.txt`. The publisher downloads those assets and verifies their checksum and exact source commit before completing.

Live PlexonCraft migration/cutover/runtime certification may remain `NOT_EXECUTED` and is a post-release operational follow-up.
